手眼外参标定（方法 A）
======================

推荐：在主程序里做（可点采样位）
--------------------------------
  python demo_pick_square.py --pick --confirm

  1. 标定板固定桌面，切「右臂(相机)」
  2. 勾选顶栏「手眼标定」→ 出现 S1–S12 采样位
  3. 用法（速度自动封顶 ≤0.06，走安全路径，每段等到位）：
       · 单击 S*     → 去该位（再点「记录姿态」）
       · 右键 S*     → 去该位并自动记录
       · 「去下一位并记」→ 按顺序下一位
       · 「自动采12组」→ 确认后整段跑完（「停序列」/「停止/解锁」可中断）
  4. 偏近(board_z 过小)或看不清板会跳过；到位后停 0.5s 再读实机位姿
  5. 「求解手眼」会对比多种算法（见下），看板RMS + AX残差
  6. 残差较小再「写回外参」（只改 camera_on_ee，不动 plate_bias）
  7. 重启或再「外参验参」抽检

求解器（求解时自动全跑，按「板在基座系重合 RMS」优选）
------------------------------------------------
  · tsai / park          经典 AX=XB
  · fixR_yaml+t_*        固定 yaml 旋转，只解平移（姿态已知时）
  · park+board_refine    Park 初值 + 板系一致性非线性精修（通常最好）
  · yamlR+t_refine       固定 yaml 旋转精修平移

  若 fixR_yaml 的板RMS ≫ park，说明当前数据与手调姿态不一致，
  不宜强行固定旋转；应采更多斜视姿态或检查板/法兰读数。

独立脚本
--------
  python calibrate_handeye_charuco.py --solve-only
  python calibrate_handeye_charuco.py --solve-only --write-yaml

理想：板RMS <5mm，且 AX 旋转 <1°、平移 <5mm；>10mm 勿轻易写回。
采样位相对 yaml「看板位」偏移，保守、不含大幅压近。
